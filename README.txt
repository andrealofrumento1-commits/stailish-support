Per usarlo in App Store Connect servono URL PUBBLICI.
Puoi pubblicare questa cartella su GitHub Pages, Netlify, Vercel o qualsiasi hosting statico.

URL attesi dopo la pubblicazione, ad esempio:
https://tuodominio.it/
https://tuodominio.it/privacy.html
https://tuodominio.it/terms.html

Campi App Store Connect:
- URL di assistenza -> homepage / index.html
- URL Privacy Policy -> privacy.html
- Terms of Use -> terms.html quando richiesto

Nota:
La Privacy Policy deve corrispondere alle pratiche effettive dell'app e alle risposte della sezione App Privacy di App Store Connect.
